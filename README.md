# Aqua Nova

A lightweight, frontend-only showcase for customized clear PET water bottles and their QR-powered customer experiences.

The main page is a responsive, scrollable HTML experience styled to match the supplied Aqua Nova reference: deep navy surfaces, electric-blue accents, cyan highlights and bottle imagery. All page copy and contact details remain selectable HTML. `/c/shrishti-solutions` presents the supplied Shrishti Solutions reference. The uploaded `assets/photos/` folder is intentionally excluded from Git and Vercel deployments.

## Run locally

Serve this folder with a static file server. Vercel rewrites `/c/:slug` to the app entry point so the sample customer routes work on direct visits and refreshes. The production site is available at [aqua-nova-theta.vercel.app](https://aqua-nova-theta.vercel.app).

## Included

- Responsive Aqua Nova homepage with selectable HTML text, bottle imagery, product and label concepts, QR experience, and clickable email, phone, WhatsApp, GitHub and LinkedIn links.
- Full-page Shrishti Solutions reference page with call, WhatsApp and map links.
- Sample customer pages at `/c/shrishti-solutions`, `/c/bluebird-cafe` and `/c/summit-2027`.
- Customer vCard download and sample menu category navigation.
- SEO metadata, robots.txt, sitemap.xml, favicon and Vercel route rewrites.

All data is static and local to the frontend. The sample pages demonstrate the customer experience; live editable QR destinations, customer administration, order processing and pricing require a future backend. Connect the actual business WhatsApp number and configure a production domain before distributing physical QR labels.
